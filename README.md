# lueurs-audio

Dépôt créé pour accueillir le fichier audio `musique.m4a` (~2 min).

## Statut actuel

Le fichier audio original fait **1,9 Mo**.  
Les outils disponibles dans cette interface ont une limite de taille pour les arguments, ce qui empêche d’uploader un binaire (ou même son base64) d’un coup.

J’ai essayé de le découper en base64 + plusieurs parties, mais ça reste trop lourd pour l’outil.

## Que faire ?

**Quand tu auras un ordi ou une meilleure connexion :**
1. Va sur https://github.com/spectrus-corp/lueurs-audio
2. **Add file → Upload files**
3. Dépose `musique.m4a`
4. Commit

**Sur mobile (GitHub app recommandée) :**
L’application GitHub officielle gère mieux l’upload de fichiers que le navigateur.

Le dépôt est prêt et t’appartient, il n’y a plus qu’à y mettre le fichier quand tu pourras.
